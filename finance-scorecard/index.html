Do the “real” AI coding workflows hold up?

Proven

Matt Pocock’s skills set the discipline: specs, vertical-slice tickets, test-first builds, code review and retros. A parent session ran child sessions in parallel, with auto-merge after screenshot review.

Can a product person design in code instead of Figma?

Promising

Much of the late polish happened in code: I dictated tweaks (“slightly increase the line weight”), saw them on the phone in seconds, and kept competing prototypes on a branch to compare. Figma stayed useful for the first big layout decision.

Figma still owned the initial Net Cash design; code owned the rest. Figma and Mobbin connectors were flaky in cloud sessions.

Takeaways for how we build

The big one

Roles are blurring into competencies.

The future of product development is multidisciplinary builders. Engineers design and prototype. Product people build and test real software. Designers refine and prototype experiences in code, and handoffs get lighter.

Claude Code isn’t just for engineers

The future of product development has product managers and designers working in Claude Code alongside engineers, all on one shared end-to-end workflow.

Design and iteration move into code

I prototyped several coded versions of an idea inside a working app, refined them conversationally, and kept the best. It works at any fidelity, from a quick sketch to the real app.

Code can tune the experience

Claude built toggles and sliders into the app so I could fine-tune spacing, weight and motion by feel. That closed the last mile without a round of handoffs.

The connected toolchain is essential

Figma and Mobbin through MCP, tickets in GitHub or Jira, a real backend and bank data, all wired into one harness. The value is in the full loop, not any single tool.

Skills can codify how Ally builds

Skills turn our product process into something repeatable. They can raise the pace of every product person and give us a recognizable Ally way of building.

Use the right agent for the job

Platforms have different strengths. Codex’s voice mode was far better for real-time spoken sessions; Claude Code led on building. A multi-agent approach gets the best of each.

This is a career skill

Matt Pocock’s engineering skills taught me real software discipline. Five years from now, I expect every product person to be comfortable building out ideas in Claude Code and tools like it.
